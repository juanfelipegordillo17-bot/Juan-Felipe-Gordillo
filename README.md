## 🚀 Featured Projects

### 🚲 RideX — Smart Bicycle

An IoT-based smart bicycle system designed to improve **security, monitoring and automation**.

**Features include:**

* 📍 GPS tracking
* 📱 Mobile application
* 🔐 Electronic locking system
* 🚨 Motion detection and alarm
* 💡 Automatic lighting
* 📡 IoT connectivity
* ☁️ Firebase real-time data

**Tech:** `ESP32` `Flutter` `Firebase` `GPS` `MPU6050` `IoT`

---

### ⚡ Enerlyx — Smart Energy Monitoring

A smart energy monitoring system designed to help users understand and manage their electricity consumption.

The project combines **sensors, embedded systems, data visualization and user-friendly interfaces** to transform electrical measurements into useful information.

**Tech:** `ESP32` `PZEM` `IoT` `JavaScript` `Vite` `HTML` `Data Visualization`

---

### 🤖 MiniSumo Robot

An autonomous MiniSumo robot designed for robotic competitions.

The system uses distance sensors to detect opponents and line sensors to keep the robot inside the arena.

**Tech:** `ESP32` `VL53L0X` `TCRT5000` `TB6612FNG` `N20 Motors`

---

A personal AI assistant project focused on creating an intelligent system capable of interacting with different services, executing tasks and evolving into a more complete personal assistant.
